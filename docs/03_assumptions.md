# 3. 가정

모든 수치는 시뮬레이션용 가정입니다. 출처 확인이 끝난 항목은 표시합니다.

| 항목 | 값 | 출처 확인 |
|---|---|---|
| 반품률 | 15% | ☐ |
| 직송 가능 비율 | 20% (민감도 10~40%) | ☐ |
| 거점 수 | 창원 10곳 (가상 위치) | 가정 |
| 택배 운임 | 구간당 2,500원 + km당 30원 | ☐ |
| 검수비 | 거점 1,000원 / 판매자 창고 2,000원 | ☐ |
| 재입고비 | 500원 | ☐ |
| 거점 취급비 | 500원 | ☐ |
| 보관비 | 하루 200원 | ☐ |
| 판매자 창고 위치 | 수도권 300km, 60% | ☐ |
| 탄소 | 구간당 0.18kg + 소포 km당 0.0012kg | ☐ |
